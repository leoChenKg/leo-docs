# 数字唱名练习

先按顺序读出数字对应的唱名，读完一整组后，再查看答案自行核对。

{{"demo":"note-reading"}}

## 怎么练习

1. 选择要练的数字、每组长度，以及是否允许相邻数字重复。默认练习全部 `1～7`，每组 8 个。
2. 从左到右读出唱名，遇到不熟悉的数字可以停下来想一想。
3. 查看答案，逐个核对唱名。点击每个答案下的喇叭，可以听这个数字对应的参考单音；点击“播放整组答案”，则从头依次播放，当前音符会高亮。
4. 可以随时停止播放，隐藏答案重读本组，或生成新题继续练习。点击另一单音或重新播放整组，会替换当前播放。

修改设置会立即生成新题并隐藏答案；隐藏答案、换题、重置、切到源码页签或离开页面时，播放会停止。刚开始可以只选少量数字，熟悉后再扩大范围。

## 唱名对应

本练习采用 `1 → do`、`2 → re`、`3 → mi`、`4 → fa`、`5 → sol`、`6 → la`、`7 → si` 的写法。

## 听参考单音

本练习的参考音固定采用 **C 大调，1 = C4（中央 C）**，按十二平均律、A4 = 440 Hz 定音。数字与参考音的对应如下：

| 数字 | 唱名 | 本练习的参考音 |
| --- | --- | --- |
| 1 | do | C4 |
| 2 | re | D4 |
| 3 | mi | E4 |
| 4 | fa | F4 |
| 5 | sol | G4 |
| 6 | la | A4 |
| 7 | si | B4 |

听到的是合成单音，用于比较音高；唱名的读法仍由文字标明。整组播放在音符间留有短暂停顿，方便逐个核对，重复数字也会分别发声。这是听音参考，不包含人声唱名示范或自动评分。

简谱的数字表示调内音级，具体音高还取决于调号和八度。本页选择 C 大调作为固定示范，不表示所有简谱中的 `1` 都是 C4。

声音只在点击播放后产生，无需录音或麦克风权限。若没有听到声音，可检查设备音量和浏览器标签页是否静音，再点击播放。浏览器无法播放时，仍可使用文字答案。

练习目标是熟悉数字与唱名的对应关系，由自己核对读音；参考音可用于跟听，不要求唱准音高或节奏。

## 十二平均律中的音程关系

十二平均律把一个八度按**频率比**等分为 12 个半音，每个半音是 100 音分。相邻两音的频率之比都是 $2^{1/12}:1$，也就是后一音的频率为前一音的 $2^{1/12}$ 倍。向上相隔 $n$ 个半音时，频率比为 $2^{n/12}:1$；走完 12 格就到达纯八度，频率恰好翻倍。相等的是每一步的频率比，以及用音分表示的音高距离；相邻频率的 Hz 差值并不相等。

下图只计算**向上、不超过一个八度**的距离。选择任意起音后，外圈节点给出目标音和上行半音数，辐射线只连接起音与目标音，不用长度表示音程大小。切换 12 个起音，就可以查看任意两个音级在一个八度内的上行半音距离。中心到自身是 0 个半音，外圈顶部的同名音则是高八度的 12 个半音。

半音数与常用音程名的对应如下。表中 0 表示同一音高，12 表示高八度的同名音。

| 上行半音数 | 音分 | 常用音程名 |
| ---: | ---: | --- |
| 0 | 0 | 纯一度（同音高） |
| 1 | 100 | 小二度 |
| 2 | 200 | 大二度 |
| 3 | 300 | 小三度 |
| 4 | 400 | 大三度 |
| 5 | 500 | 纯四度 |
| 6 | 600 | 增四度或减五度（三全音） |
| 7 | 700 | 纯五度 |
| 8 | 800 | 小六度 |
| 9 | 900 | 大六度 |
| 10 | 1000 | 小七度 |
| 11 | 1100 | 大七度 |
| 12 | 1200 | 纯八度 |

本页的 C 大调 `1～7` 只取十二平均律中的 C、D、E、F、G、A、B 七个位置，相对 C 的上行半音数分别是 0、2、4、5、7、9、11。因此相邻数字之间并不总是同样远：`3 → 4`（E → F）和 `7 → 高音 1`（B → C）只有 1 个半音，其余相邻音级有 2 个半音，形成 `2–2–1–2–2–2–1` 的步型。数字差相同也不代表音程性质相同：`1 → 3`（C → E）是 4 个半音的大三度，`2 → 4`（D → F）则是 3 个半音的小三度。

`C♯/D♭`、`D♯/E♭` 等变化音在十二平均律中等高，但记谱名称和调内功能不同。上表是按半音距离给出的常用对应；严格的音程名还取决于两个音名的字母跨度和升降号写法，尤其是相隔 6 个半音时可能写作增四度或减五度。
