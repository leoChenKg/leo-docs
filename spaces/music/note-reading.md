# 数字唱名练习

先按顺序读出数字对应的唱名，读完一整组后，再查看答案自行核对。

{{"demo":"note-reading"}}

## 怎么练习

1. 选择要练的数字、每组长度，以及是否允许相邻数字重复。默认练习全部 `1～7`，每组 8 个。
2. 从左到右读出唱名，遇到不熟悉的数字可以停下来想一想。
3. 查看答案，逐个核对唱名。点击每个答案下的喇叭，可以听这个数字对应的参考单音；点击“播放整组答案”，则从头依次播放，当前音符会高亮。
4. 可以随时停止播放，隐藏答案重读本组，或生成新题继续练习。点击另一单音或重新播放整组，会替换当前播放。

修改设置会立即生成新题并隐藏答案；隐藏答案、换题、重置、切到源码页签或离开页面时，播放会停止。刚开始可以只选少量数字，熟悉后再扩大范围。

## 唱名对应

本练习采用 `1 → do`、`2 → re`、`3 → mi`、`4 → fa`、`5 → sol`、`6 → la`、`7 → si` 的写法。

## 听参考单音

本练习的参考音固定采用 **C 大调，1 = C4（中央 C）**，按十二平均律、A4 = 440 Hz 定音。数字与参考音的对应如下：

| 数字 | 唱名 | 本练习的参考音 |
| --- | --- | --- |
| 1 | do | C4 |
| 2 | re | D4 |
| 3 | mi | E4 |
| 4 | fa | F4 |
| 5 | sol | G4 |
| 6 | la | A4 |
| 7 | si | B4 |

听到的是合成单音，用于比较音高；唱名的读法仍由文字标明。整组播放在音符间留有短暂停顿，方便逐个核对，重复数字也会分别发声。这是听音参考，不包含人声唱名示范或自动评分。

简谱的数字表示调内音级，具体音高还取决于调号和八度。本页选择 C 大调作为固定示范，不表示所有简谱中的 `1` 都是 C4。

声音只在点击播放后产生，无需录音或麦克风权限。若没有听到声音，可检查设备音量和浏览器标签页是否静音，再点击播放。浏览器无法播放时，仍可使用文字答案。

练习目标是熟悉数字与唱名的对应关系，由自己核对读音；参考音可用于跟听，不要求唱准音高或节奏。
