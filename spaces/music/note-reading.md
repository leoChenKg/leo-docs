# 数字唱名练习

先按顺序读出数字对应的唱名，读完一整组后，再查看答案自行核对。

{{"demo":"note-reading"}}

## 怎么练习

1. 选择要练的数字、每组长度，以及是否允许相邻数字重复。默认练习全部 `1～7`，每组 8 个。
2. 从左到右读出唱名，遇到不熟悉的数字可以停下来想一想。
3. 查看答案，逐个核对。可以隐藏答案重读本组，也可以换一组继续练习。

修改设置会立即生成新题并隐藏答案。刚开始可以只选少量数字，熟悉后再扩大范围。

## 唱名对应

本练习采用 `1 → do`、`2 → re`、`3 → mi`、`4 → fa`、`5 → sol`、`6 → la`、`7 → si` 的写法。

练习目标是熟悉数字与唱名的对应关系，由自己核对读音；不要求唱准音高或节奏。
