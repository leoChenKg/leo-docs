# Java

这个空间当前覆盖 Java 的文件与 I/O 专题。文章从具体问题出发，解释 API 的职责、给出可运行示例，并说明失败情形和工程中的选择；后续新增语言、集合或并发专题时，再按各自知识边界扩展目录。

## 推荐入口

[文件与 I/O](./io/)按主题分为两个学习目录，每个目录都包含原理、示例和对应的面试练习：

1. [文件操作](./io/files/)：学习路径、流、编码、资源关闭和可靠写入，再用 40 道面试题检验理解。
2. [NIO 与 NIO.2](./io/nio/)：从 Buffer、Channel 进入 Selector、现代文件系统和异步通道，最后完成 42 道面试问答。

初学时先掌握流、编码和资源关闭，再按任务选择后续路线。只需要创建、遍历或移动文件时，可以直接进入 [Path 与 Files](./io/nio/filesystem/)，不必先学完网络编程；维护旧接口时，再重点学习 [File 类](./io/files/file/)。准备面试时，进入相应专题的题库，再按薄弱点返回正文。
