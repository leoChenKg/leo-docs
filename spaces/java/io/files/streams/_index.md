# 流与编码

文件内容的读取可以分为三个问题：字节怎样完整传输，怎样解释为文本，资源和异常由谁管理。按下列顺序学习，每篇都包含示例与易错点。

## 阅读顺序

1. [字节流与读写](./reading.md)：类型职责、EOF、短读、缓冲，以及创建、覆盖和追加。
2. [字符编码与文本](./encoding.md)：UTF-8、char 与码点、跨块解码、逐行读取。
3. [资源管理与写入保证](./resources.md)：TWR、惰性流、异常、flush/force，以及综合实验。

## 学完后怎样验证

用[第 1–17 题](../interview/streams.md)检验基础，再完成[复制与日志处理场景](../interview/scenarios.md)。创建目录、查询属性或改名等文件系统操作另见[File 专题](../file/)。
