# Java 文件操作面试题：40 题分组练习

本题库按知识主题拆成四篇，保留连续的 1–40 题编号。每题提供参考答案与追问或易错点，用于检查能否解释原因、识别错误和选择实现；题目编排不代表企业面试频率统计。

## 阅读顺序与题号映射

先完成第 1–25 题，再补齐第 26–34 题，最后独立完成第 35–40 题。已有基础时，可以从场景题开始，再按薄弱点回看原理。

## 答题方式与版本约定

每题先给结论，再说明适用条件，最后举出一个反例；能应对追问后再进入下一组。重点区分路径与文件、字节与字符、EOF 与暂时不可读、刷新与持久化、原子发布与事务、路径相等与对象相同、就绪通知与完成通知。

答案以 Java SE 25 官方 API 契约核对，备考重点面向 Java 8、11、17、21；引用的 Oracle Java Tutorials 以 JDK 8 为基础，版本变化在题目中说明。场景题保留可验证的 Java 8 方法和一段明确标注的错误代码，所需 import 与调用前提在对应题目中给出。

## 两套题库怎样配合

文件操作 40 题检查“怎样把文件处理写正确”；[NIO 的 42 题](../../nio/interview/)进一步检查状态推进、网络协议和异步生命周期。路径、Buffer、文件锁等主题有意交叉，答案各自保留必要上下文。已经能完整回答一个主题时，按下表补充另一套的追问即可，不必把相同概念重复背两轮。
