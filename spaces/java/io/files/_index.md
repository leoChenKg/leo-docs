# 文件操作

本专题面向已了解 Java 类、方法和基本控制流程的读者，目标是能正确读写文件、管理资源并解释失败原因。原理文章保留紧密相关的示例，较完整的实验按任务单独组织；面试练习集中管理。

## 与 NIO 专题的衔接

文件操作侧重正确使用与失败处理。Buffer、Channel、Selector、映射、现代文件系统和异步通道的完整机制集中在相邻的[NIO 与 NIO.2](../nio/)专题，避免在两个目录重复维护同一段教学。

- [Buffer、Channel 与 I/O 模型](../nio/basics/)：缓冲区状态、通道进度、映射与性能。
- [Path、Files 与目录监听](../nio/filesystem/)：现代文件系统、链接、遍历、属性和监听。
- [异步通道](../nio/async-channels/)：提交、完成通知和资源生命周期。
