# 构建与发布演示

选择 Mac ARM64 或 x64 后，依次执行：提交构建参数 → 分配构建机与检出代码 → 安装依赖并查询已有包 → 准备配置 → 编译应用 → 打包签名 → 上传 AppHub → 查看独立公证结果 → 安装包回测 → Downton 转存 CDN → 生成热更新 → Mars 录入版本 → 升级回测 → 30% 灰度 → 观察与确认全量 → 客户端更新。

每步展示操作方、输入、输出、相关命令，以及累计生成的安装包、制品记录、发布文件和灰度状态。回测与全量确认处，选择“未通过”会停在当前步骤；选择“通过”后才能继续。“上一步”回退并恢复那一步的状态，“重新开始”清空本轮结果。

版本 0.0.1、0.0.2 和构建号 90001、90002 均为示意数据。演示只覆盖未命中已有包的新构建主线，且将公证和人工环节依次展开便于阅读，不是后端自动状态机。不会连接公司系统，也不会执行真实构建、签名、公证、上传或发布。
