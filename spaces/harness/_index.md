# Harness 体系学习

这个空间记录我对团队 Harness 体系的学习，范围包括 Tutor Compass、Multica、Runtime、Agent Skills 和 Monkey E2E。

学习目标是能够解释它为什么这样设计、代码如何实现、失败时会怎样，以及什么情况下值得改进。当前实现是研究对象，每个设计的收益和代价都需要结合实际问题判断。

## 从哪里开始

先读 [Harness 全局认知：从需求到代码交付](./system-overview.md)。这篇用一张全局图和一个前端需求，讲清各部分的职责以及它们怎样配合，是后续读源码时的定位入口。

## 后续记录围绕什么展开

后续按实际学习进展补充，围绕四个问题组织：

1. **为什么建**：原来的研发方式遇到了什么问题，体系如何演进。
2. **怎么实现**：任务状态、Agent 执行、工作环境、测试和证据如何连接。
3. **哪里有取舍**：当前设计解决了什么，又留下什么限制。
4. **如何验证改进**：用具体案例、源码和实验判断优化是否有效。

笔记中区分文档记录、代码事实、自己的推断和实验结果。以后整理面试案例时，也分别说明团队已有能力与自己实际完成的工作。
