# 八个月学习规划：面向 AI 应用与桌面端的全栈能力建设

## 学习背景

目前已熟练掌握前端开发，具备基础的 Electron 桌面端开发知识。

计划利用未来八个月，每天投入两到三小时，系统学习 Java 后端、Python、AI Agent、harness、Electron，以及互联网基础设施与系统架构，同时巩固前端能力。

职业目标是转向 **AI 应用或 AI 桌面端相关岗位**，逐步建立能够独立承担全栈开发工作的能力。

## 能力定位

整体能力结构分为三个部分：

- **全栈基础：** 前端开发、Java 后端、数据库、基础设施与系统架构。
- **核心方向：** Python、AI Agent 开发、harness 工程。
- **重点交付能力：** Electron 桌面端开发。

Java 作为必修的主要后端技术栈，保持较高学习权重。Python 作为 AI 工程的主要实践语言，用于 Agent 开发、评测、实验和相关源码研究。TypeScript 继续用于前端与 Electron 开发。

学习目标是形成扎实的知识基础和独立解决问题的能力，并在最后阶段通过综合实践验证这些能力。

## 学习原则

### 先掌握模块，再进行综合实践

按照知识之间的前置依赖，逐步学习各个模块。每个阶段集中掌握一个主要模块，通过独立练习巩固理解，再进入后续内容。

完整成品放在最后阶段考虑。前面的学习范围依据知识的重要性和能力建设需要确定，不围绕最终产品的功能倒推所有学习内容。

### 理论、练习与验证结合

每个模块都应包含必要的概念学习、独立练习和复盘。

判断是否掌握，主要看能否：

- 用自己的语言解释核心概念及其适用场景。
- 独立完成对应练习。
- 定位并解决典型问题。
- 说明不同方案的取舍。

学习过程中可以使用 AI 辅助解释、检查和调试，但应能够独立理解关键实现与执行过程。

### 控制学习广度，保证主要方向的深度

优先掌握通用原理和常用工程能力，同类框架选择一个作为主要学习对象。

高级分布式架构、复杂基础设施、模型训练和多个框架的全面比较，作为后续扩展内容。前沿技术保持适量跟踪，避免挤占核心知识的学习时间。

## 知识大纲

以下只列出需要学习的大知识点，具体内容在进入对应模块时再展开。

| 知识模块 | 主要知识点 |
| --- | --- |
| **计算机基础** | 数据结构与算法基础、操作系统基础、计算机网络、Web 通信基础 |
| **Java 后端** | Java 核心知识、Java 并发、JVM、Spring／Spring Boot、身份认证与权限管理、数据库与 SQL、持久化框架、缓存、消息队列、后端测试与工程化 |
| **Python** | Python 核心知识、异步与并发、Python 工程化、API 服务开发、测试与调试 |
| **AI 应用与 Agent** | 大模型基础、提示词工程、上下文工程、结构化输出、工具调用、RAG、MCP、Agent 工作流与开发框架、AI 评测 |
| **Harness 工程** | 需求与规格管理、任务规划与编排、执行环境与工具系统、上下文与记忆管理、任务状态与恢复、多 Agent 协作、权限与执行边界、自动化验证与反馈、可观测性与成本控制、源码与架构研究 |
| **前端深化** | JavaScript／TypeScript 深入、浏览器原理、前端框架原理、状态管理、前端工程化、性能优化、前端测试、前沿技术跟踪 |

不同知识点采用不同的掌握要求：

| 掌握层级 | 要求 |
| --- | --- |
| **重点掌握** | 理解原理，能够独立实现并排查常见问题 |
| **熟练使用** | 理解用途与边界，能够查阅文档完成实际任务 |
| **理解概念** | 知道解决什么问题、何时适用，后续按需要深入 |

具体层级在各模块的学习计划中确定，不要求对大纲中的全部内容投入相同深度。

## 时间与学习安排

八个月每天学习两到三小时，理论投入约为 480–720 小时。考虑工作、精力波动和返工，先以 **约 450 小时的有效投入**作为规划基准，剩余时间用于机动调整。

| 学习方向 | 参考投入 |
| --- | ---: |
| Java 后端 | 160 小时 |
| Python、AI Agent 与 harness | 150 小时 |
| Electron | 75 小时 |
| 基础设施与系统架构 | 40 小时 |
| 前端深化 | 25 小时 |
| **合计** | **450 小时** |

计算机基础结合相关模块安排。以上时间包含练习、调试、复盘，以及最后阶段的综合实践；综合实践按任务归入对应方向，不额外叠加预算。

整体学习过程分为三个阶段：

1. **模块学习：** 按前置依赖学习重要知识，完成独立练习。
2. **模块验收与补缺：** 检查理解和实践能力，处理明显薄弱环节。
3. **综合实践：** 在最后阶段整合已学知识，进行完整系统的实现或优化。

Java 后端、Python、AI Agent、harness 构成主要递进路径。前端、Electron 和基础设施分别安排集中学习模块，并根据必要的前置知识调整顺序。

## 最终综合实践：需求全流程自动化 Harness

最终希望实现一个能够支持 **单个需求全流程自动化实现**的 harness 成品。

公司目前已有相关项目，因此最后阶段以公司现有系统为基础，开展架构理解、问题分析、能力优化和效果验证。

目标流程包括：

**需求理解与澄清 → 规格与验收标准 → 方案设计 → 任务拆解 → 编码实现 → 测试验证 → 评审与修复 → 交付验收。**

综合实践重点关注：

- 需求如何转化为明确、可验证的执行目标。
- 各阶段如何衔接、传递上下文和管理任务状态。
- 执行失败、中断和重复操作如何处理。
- 如何自动验证结果并形成修复反馈。
- 如何衡量完成质量、稳定性、耗时和成本。
- 如何确定自动化范围、权限与人工介入边界。

Electron 作为独立的重要能力学习。是否将其用于 harness 的操作界面，在综合实践阶段根据公司现有架构和实际需求决定。

## 预期学习成果

完成这一轮学习后，期望能够：

- 独立开发和维护常见 Java 后端服务。
- 使用 Python 开发、调试和评测 AI Agent。
- 理解 harness 的关键机制，并通过实验改进其表现。
- 交付具备基本安全性、稳定性和更新能力的 Electron 应用。
- 完成常见应用的部署、监控、故障排查与恢复。
- 在公司现有 harness 项目中承担具体模块的研究、实现和优化工作。

最终保留模块学习笔记、独立练习、问题复盘、综合实践记录和评测结果，作为后续深化学习与职业发展的依据。
